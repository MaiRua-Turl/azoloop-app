# AzoLoop

Nguyên mẫu ứng dụng hỗ trợ đề xuất công thức phân bón Azolla.

## Tệp bắt buộc

Trước khi triển khai, đặt file `random_forest_azolla_demo.pkl` cạnh `app.py`.

## Cấu trúc

```text
app.py
random_forest_azolla_demo.pkl
requirements.txt
render.yaml
assets/
```

## Render

- Build command: `pip install -r requirements.txt`
- Start command: `python app.py`

Kết quả hiện dùng dữ liệu mô phỏng và chưa được xác nhận bằng phân tích phòng thí nghiệm.
